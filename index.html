Nasıl kullanılır?
  1. Gmail: Ayarlar → Tüm ayarları göster → İmza → Yeni oluştur → kutuya yapıştırın (Ctrl+V / Cmd+V).
  2. Outlook: Ayarlar → Hesaplar → İmzalar → Yeni imza → yapıştırın.
  3. Görseller görünmüyorsa "HTML Kodunu Kopyala" ile HTML modunda ekleyin.
